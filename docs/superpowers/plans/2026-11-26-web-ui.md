**Tech Stack:** Python 3.12、Streamlit ≥1.45、fpdf2 ≥2.8.6、LangGraph、pytest。

  - `_new_graph(config: dict, stats) -> TradingAgentsGraph`（唯一构造点，测试替换它）

  - `_infer_active_stage(tracker: ProgressTracker) -> None`
  - `_run(ticker: str, trade_date: str, config: dict, tracker: ProgressTracker, fresh: bool = False) -> None`
  - `run_analysis_in_thread(ticker: str, trade_date: str, config: dict, tracker: ProgressTracker, fresh: bool = False) -> threading.Thread`

**`_run` 必须按此顺序：**

```python
graph = _new_graph(config, stats)
if fresh:
    graph.clear_checkpoint_on_success(ticker, trade_date)
tid = graph.begin_checkpoint(ticker, trade_date)
init = graph.create_run_state(ticker, trade_date)
args = graph.propagator.get_graph_args(callbacks=[stats])
if tid is not None:
    args.setdefault("config", {}).setdefault("configurable", {})["thread_id"] = tid
merged = {}
stream = graph.stream_run(graph.checkpoint_input(init), **args)
try:
    for _messages, chunk in stream:
        tracker.wait_if_paused()
        if tracker.stop_requested: break
        if chunk is not None:
            merged.update(chunk)
            _detect_completed_stages(merged, tracker)
            _infer_active_stage(tracker)
        record_incomplete_task(ticker, trade_date,
                               status="paused" if tracker.is_paused else "running",
                               completed_stages=tracker.completed_stages)
        s = stats.get_stats()
        tracker.update_stats(s["llm_calls"], s["tool_calls"], s["tokens_in"], s["tokens_out"])
finally:
    stream.close()
    graph.end_checkpoint()
```

循环后用 `if tracker.stop_requested:` 走停止清理：`clear_incomplete_task` → `graph.clear_checkpoint_on_success(ticker, trade_date)` → `tracker.mark_stopped()`。

正常结束：

```python
normalize_report_state_mentions(merged, ticker)
graph.record_decision(ticker, trade_date, merged)
graph.clear_checkpoint_on_success(ticker, trade_date)
saved = graph.save_reports(merged, ticker)
tracker.saved_path = str(saved)
tracker.mark_complete(merged, run_rating(merged))
clear_incomplete_task(ticker, trade_date)
```
